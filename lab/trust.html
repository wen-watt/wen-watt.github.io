Trust is not a promise; it is a link you can click. This page lists the key claims across the almanac and the Lab, each with a status and its sources. Where we could not verify something, we say so. Where sources disagree, we show both. That is the whole method.

Four principles of trust

  1. Open. Code, data and sources are public. Nothing important sits behind a login.
  2. Free. The Lab's code is Apache-2.0. No fees, no gatekeeping, no paid tier.
  3. Universal. The models work with any token and any company; the WEN contract travels with them as the community's signature.
  4. Checkable. Every claim below has a status and a source. If it cannot be checked, it is marked.

A field for companies and new kinds of banks

Banks and payment companies decide on evidence, not on enthusiasm. An open, free, documented and tested set of models lowers the cost of their first experiment to almost zero: a team can read the code in an afternoon, run the local tests in a minute and repeat the devnet run in ten. That is how a meme coin's technical heritage becomes useful to institutions — not by asking for trust, but by making checking easy. Regulation, licensing and audits remain their responsibility; the Lab gives them a transparent starting point.

Where Wen fits in this model

A universal coin needs universal trust. WEN's contract is public, WNS is open source under Apache-2.0, and the Lab adds free models anyone can test. That combination — open, free, universal, checkable — is what turns a meme into a field where companies, fintechs and even new kinds of banks can build without asking anyone's permission.

Open use policy

  • Free and open. All Lab code is released under the Apache License 2.0, the same license as the Wen Program Library. Use it, change it, ship it, commercially or not; keep the license notice.
  • Open tools only. Built on public, documented tools: Solana SPL Token-2022 (Token Extensions), the token layout of the Wen New Standard (WNS), Solana Pay, and LiteSVM for local testing.
  • The rule: always verify your own model. Run the tests, start on devnet, read the official documentation, review every account and amount, and get an independent audit before any mainnet use. A model that is not checked is not a model, it is a guess.
  • Not audited, not advice. These are educational examples. They are not financial, legal or tax advice, and not a licensed payment or banking product. Payments, stablecoins and acquiring are regulated activities in most countries.
  • Security. Never paste a private key into a website. Do not install the npm package @wen-community/wen-new-standard: npm removed it as malicious. Build from official sources.
