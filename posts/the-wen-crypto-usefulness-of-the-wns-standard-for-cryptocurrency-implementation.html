What WNS Is Useful For: Five Features, Six Tested Models

October 21, 2025

Almanac guide Written by the almanac itself. Every claim links to a source you can open or to a model you can run and check.

A standard is only as good as what people can do with it. The Wen New Standard (WNS) was proposed on January 25, 2024 as a light way to make NFTs on Solana's Token-2022. This guide answers the practical question the original blog kept asking: what is it useful for? — in plain words, feature by feature, with a free model for each use that anyone can run and check in Wen Open Lab.

The idea in one paragraph

Most NFT systems on Solana put the important parts — names, collections, royalties — in separate programs run by someone else. WNS moves them into the token itself, using the extensions built into Token-2022 (Solana token extensions). Fewer moving parts means lower cost, no middleman to pay, and rules that travel with the token wherever it goes (WNS 0.0 proposal).

Six tested models

Each use above is a working model in Wen Open Lab — free code, tested step by step, which you can repeat yourself on Solana's public test network:

  1. Receipts and warranty cards — one receipt token per order; it cannot be forged or lost.
  2. Creator royalties — the artist is paid on every resale by the token's own rule.
  3. B2B invoices — an invoice as a token both companies can see and check.
  4. Payments bridge — take a payment, confirm it, tell the shop: card acquiring on open rails.
  5. Payment simulator — try the whole flow without spending anything.
  6. Devnet run — repeat it all yourself and check every step in the explorer.

Who it helps

  • Shops — receipts and warranties customers cannot lose; payments without a card terminal (see how card networks approach the same goal).
  • Artists and creators — royalties that do not depend on a marketplace's goodwill.
  • Companies — invoices and records both sides can verify.
  • Communities — badges and proofs of attendance that cannot be bought.
  • Everyone — public records anyone can check, which is the reason this almanac exists (the same data, used for good).

Honest limits

  • WNS is a standard and a set of models, not a guarantee that any business uses it today.
  • The Lab models run on devnet, the public test network; real-world use needs audits and legal checks.
  • The WEN token itself is a regular Solana token; the royalties and receipts belong to NFTs made with WNS.
