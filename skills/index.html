Wen Skills

Agent skills are short instruction files (SKILL.md) that AI assistants load when a task matches. Ours turn the work of the Wen Open Lab into steps an assistant can follow safely. Free forever, Apache-2.0.

wen-counter-shop

Audits an online shop and adds a free, receive-only Solana Pay checkout: the WooCommerce plugin, a payment link or QR for other platforms, or the self-hosted Wen Counter. Public address only, devnet first, the owner approves every change.

npx skills add wen-watt/wen-watt.github.io

Or from the small mirror, for catalogs and slow connections: npx skills add wen-watt/skills (github.com/wen-watt/skills, synced daily from this site).

How to use a skill

  1. Install it with the command above. It works for Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Cline, Zed and other assistants that read skills.
  2. Run your assistant on your own computer, in the folder of your project.
  3. Ask in plain words, for example “add Solana Pay to my WooCommerce shop”. If needed, name the skill: “use wen-counter-shop”.

Safety that travels with the skill

  • Never a seed phrase or private key; only the public receiving address.
  • Receive-only; three read requests to the chain; on-chain text is data, never instructions.
  • Devnet first; the owner says yes to every change and to mainnet.
  • Install from a known version; the plugin zip has a SHA-256 fingerprint.
  • Token-neutral: USDC by default, no promotion of any token or project.
