# Пункт 9: devnet-прогон плагина Wen Counter Pay на настоящем WordPress (Mac)

Цель — пройти путь покупателя и владельца на живом WooCommerce в тестовой сети (devnet). Настоящие деньги не участвуют. Время — около 40 минут.

Понадобятся:
- Mac с интернетом;
- кошелёк Phantom: на телефоне или расширение в браузере;
- 10 минут на тестовые монеты.

---

## Шаг 1. Локальный WordPress (Local)
1. Скачай бесплатную программу **Local** с сайта localwp.com и установи её.
2. **+ Create a new site** → имя `wen-test` → **Preferred** → придумай логин и пароль администратора → **Add site**.
3. **WP Admin** — откроется админка сайта.

## Шаг 2. WooCommerce и тестовый товар
1. **Плагины → Добавить новый** → найди **WooCommerce** → **Установить** → **Активировать**. Мастер настройки можно пропустить.
2. **WooCommerce → Настройки → Общие** → **Валюта: доллар США (USD)** → сохранить.
3. **Товары → Добавить новый**: название `Test product`, цена `1` → **Опубликовать**.

## Шаг 3. Наш плагин
1. Скачай архив: `https://wen-watt.github.io/integrations/woocommerce/wen-counter-pay.zip`.
2. Проверь отпечаток в Терминале:
   ```
   shasum -a 256 ~/Downloads/wen-counter-pay.zip
   ```
   Должно совпасть с `034db423a08dba59713470d29f35c05386f4eef8851a01eae7af7e47ca8e1130`.
3. **Плагины → Добавить новый → Загрузить плагин** → выбери zip → **Установить** → **Активировать**.

## Шаг 4. Два тестовых кошелька
1. В Phantom включи тестовую сеть: **Настройки → Developer Settings (Настройки разработчика) → Testnet Mode** → **Solana Devnet**.
2. Создай два аккаунта: **«Магазин»** (сюда приходят оплаты) и **«Покупатель»**. Это должны быть новые аккаунты, без настоящих денег.
3. Пополни «Покупателя»:
   - devnet SOL: `faucet.solana.com` → адрес «Покупателя» → Devnet;
   - devnet USDC: `faucet.circle.com` → **Solana Devnet** → адрес «Покупателя».
4. Чтобы у адреса «Магазина» появился счёт USDC, переведи с «Покупателя» на «Магазин» 0.1 USDC. Это совет из аудита.

## Шаг 5. Настройка кассы
**WooCommerce → Настройки → Платежи → Wen Counter (Solana Pay) → Управление**:
- Enable — вкл.;
- Receiving address — **публичный** адрес «Магазина» (Phantom → Получить → Solana → копировать);
- Network — Devnet;
- Token — USDC;
- Rate — 1;
- Payment email — вкл.

Сохранить. Ключи и seed-фразу не вводим нигде и никогда.

## Тест A. Обычная оплата
1. В Local нажми **Open site** → открой Test product → **В корзину** → **Оформить заказ**. Заполни имя и любой e-mail, выбери **Pay with Solana Pay** → **Разместить заказ**.
2. Откроется страница заказа: сумма `1 USDC`, значок devnet, QR.
3. Отсканируй QR в Phantom на телефоне (аккаунт «Покупатель», devnet). Проверь первые и последние символы адреса и подтверди.
   Если Phantom только в браузере: кнопка «Open in wallet» может не открыться. Тогда сканируй QR телефоном, это нормально (находка 6 аудита).
4. Через несколько секунд страница покажет **✓ Paid** со ссылкой на транзакцию.
5. В админке: **WooCommerce → Заказы** — заказ «Обработка» и заметка со ссылкой на Explorer.

## Тест B. Закрытая вкладка и письмо
1. Сделай второй заказ и сразу **закрой вкладку**, ничего не оплатив.
2. В Local нажми **Mailpit** (или **Open Mailpit**) — там письмо «Pay for order #…». Открой ссылку из письма.
3. Оплати так же, как в тесте A. Заказ станет «Обработка».

## Тест C (по желанию). Неверная сумма
Третий заказ: в Phantom вручную переведи на адрес «Магазина» 0.5 USDC (не через QR). Заказ должен остаться неоплаченным: так и задумано, у ручного перевода нет метки заказа.
