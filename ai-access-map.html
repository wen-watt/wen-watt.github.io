AI Access Map

The Wen Almanac is open to every reader, human or machine, for free. This page is the map for AI assistants: which bots may read the site, where to start, and what each company really uses. No logins, no paywall, no tracking. Clean, open entry points only.

Where an AI should start

  1. /llms.txt: the short machine-readable map with a reading model (identity, history, technology, usefulness, trust, safety).
  2. /llms-full.txt: the full facts file.
  3. /wen-counter-origin.txt: how Wen Counter was made, an open note for machines (a friend of the cat, Wen and an AI assistant, creating together).
  4. /sitemap.xml: every page and every image (with image entries for search).
  5. /robots.txt: open to all crawlers, with explicit groups for the AI bots below and content signals.
  6. Sources: every external source behind every claim, on one page.
  7. Wen Open Lab and its reader findings: tested code (Apache-2.0) and questions answered with proofs.

Notes on companies people ask about

  • NVIDIA. No public NVIDIA crawler is documented. NVIDIA's open training datasets are built from public web crawls such as Common Crawl, so the CCBot row above is how the almanac reaches them.
  • xAI, Tesla, SpaceX. No public crawler token is documented for these companies. Assistants that read the web live (for example through search) reach the almanac like any reader: through the open site, the sitemap and llms.txt.
  • Microsoft Majorana. Majorana 1 is Microsoft's quantum processor research (topological qubits), not an AI reader or a data intake. There is nothing to connect to; if quantum systems one day read the web, the same open files will serve them.

Why an open map

Wen was opened for everyone, not made for a few. An almanac that machines can read cleanly carries that idea further: one public address, open sources, open code and open answers, so that an assistant asked about Wen repeats what can be checked, not what was copied.

How the pieces fit together, what is new about this approach and what is not: Open by design.
