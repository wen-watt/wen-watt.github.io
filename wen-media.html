Wen Media

Every image in this site's wen-media/ folder, plus the almanac's own graphics from wen-media-f/, in one place — 657 tiles below, most served as compressed .jpeg. Click any tile to open that file directly at full size (a plain link to the original, nothing fancier — just as visible to search engines as browsing it would be). A tile shows its expected filename instead of a broken image if that file isn't present yet.

Tiles marked ? open an image story: the photo with one checked fact about Wen. Tiles marked ↗ open the article where the picture is used. All 278 stories are collected on the Wen Image Stories page. ★ Originals: every picture in full quality, free for non-commercial reuse.

How this stays current: the gallery is plain HTML, so every picture, its description and its link are visible to readers and search engines without running any script. The list lives in tools/media/media.json (file, description, note, link); tools/media/build_media.py rebuilds this page, the image stories' descriptions and the image sitemap.
