Wen Media

Every image in this site's wen-media/ folder, in one place — 599 tiles below, all served as compressed .jpeg. Click any tile to open that file directly at full size (a plain link to the original, nothing fancier — just as visible to search engines as browsing it would be). A tile shows its expected filename instead of a broken image if that file isn't present yet.

Tiles marked ? open an image story: the photo with one checked fact about Wen. All 250 are collected on the Wen Image Stories page. ★ Originals: every picture in full quality, free for non-commercial reuse.

How this stays current: this page can't scan a folder by itself — no static site can. The list of filenames lives right in this page's own code, in a JavaScript array near the bottom. Whenever a new image lands in wen-media/, add its filename to that array (one line, same format as the rest) and it will show up here — no other changes needed. This also means the gallery works the same whether the page is opened straight from disk or hosted online.
