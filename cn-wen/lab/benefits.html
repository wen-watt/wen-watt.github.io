实用是世界上最重要的东西，它的衡量标准是人们能做到以前做不到的事。以下是实验室的开放模型给每个群体带来了什么、适合哪里，以及诚实地说不适合哪里。

谁获得什么

谁获得什么从这里开始
开发者基于 Solana 官方工具、可运行且经过测试的 TypeScript；本地测试环境；无需付费 SDK路线图

Wen 社区证明一个梗能留下有用的公共产品；一个去建设而不只是持有的理由WPL 综述

五种实用

  1. 无需中间人的信任。规则在代币中运行，所有人都看得见。
  2. 速度。数秒确认，而不是数天结算。
  3. 更低成本。网络费不到一美分；在模拟器里查看你的全部成本。
  4. 隐私内建。哈希上链，个人数据不上链。
  5. 开放获取。免费代码，开放标准，工具无许可费。

（暂时）不适合的地方

  • 没有钱包、也不想要钱包的顾客。
  • 法律上要求拒付式买家保护的支付。
  • 没有持牌合作方的受监管金融服务。
  • 任何未在 devnet 上测试、未经审计师审查的东西。

如何参与

  • 运行代码，试着弄坏它，然后在 X 上告诉社区你的发现（@wenwencoin）。
  • 按 Apache-2.0 把模型 fork 到你自己的项目中。
  • 关注路线图：接下来是 devnet 演示、WNS 群组注册、版税钩子示例和审计清单。

Wen 在此模型中的位置

Wen 把这一切串联起来。WEN 的故事把基于 Token-2022 的 WNS 标准带到了一百万个钱包；实验室把这份证明变成免费工具；WEN 合约作为社区的签名随每个模型流传。实用第一，关注其次，不承诺任何收益。

Wen 的主线：一个合约，处处可见

实验室的每个模型都免费且开放，并带着同一个签名：$WEN 代币合约。复制它，在你自己的文档中重复它，使用前务必在浏览器上核验。

开放使用政策

  • 免费且开放。实验室的全部代码以 Apache License 2.0 发布，与 Wen Program Library 相同。无论是否商用，都可以使用、修改、发布；请保留许可声明。
  • 只用开放工具。基于公开且有文档的工具构建：Solana SPL Token-2022（Token Extensions）、Wen New Standard（WNS）的代币布局、Solana Pay，以及用于本地测试的 LiteSVM。
  • 规则：始终核验你自己的模型。运行测试，从 devnet 开始，阅读官方文档，检查每个账户和金额，并在任何主网使用之前获得独立审计。未经核验的模型不是模型，而是猜测。
  • 未经审计，不构成建议。这些是教学示例，不构成金融、法律或税务建议，也不是持牌的支付或银行产品。在大多数国家，支付、稳定币和收单都是受监管的活动。
  • 安全。切勿把私钥粘贴到任何网站。不要安装 npm 包 @wen-community/wen-new-standard：npm 已因恶意将其移除。请从官方来源构建。
