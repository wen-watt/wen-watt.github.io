信任不是承诺，而是一个你可以点击的链接。本页列出年鉴和实验室中的关键论断，每条都标明状态和来源。我们无法核实的，就直说。来源有分歧的，两种都列出。这就是全部方法。

信任的四项原则

  1. 开放。代码、数据和来源都是公开的。重要的东西都不需要登录。
  2. 免费。实验室代码采用 Apache-2.0。没有费用，没有门槛，没有付费等级。
  3. 通用。模型适用于任何代币和任何公司；WEN 合约作为社区的签名随之流传。
  4. 可核验。下面每个论断都有状态和来源。无法核验的会标出。

企业与新型银行的试验场

银行和支付公司依据证据而不是热情做决定。一套开放、免费、有文档、经过测试的模型，把它们第一次实验的成本降到几乎为零：一个团队用一个下午读懂代码，一分钟跑完本地测试，十分钟复现 devnet 运行。这就是一枚梗币的技术遗产对机构变得有用的方式——不是要求信任，而是让核验变得容易。监管、牌照和审计仍是它们自己的责任；实验室给它们一个透明的起点。

状态说明

  • 已验证——我们亲自检查过（运行代码、查询注册表）。

开放使用政策

  • 免费且开放。实验室的全部代码以 Apache License 2.0 发布，与 Wen Program Library 相同。无论是否商用，都可以使用、修改、发布；请保留许可声明。
  • 只用开放工具。基于公开且有文档的工具构建：Solana SPL Token-2022（Token Extensions）、Wen New Standard（WNS）的代币布局、Solana Pay，以及用于本地测试的 LiteSVM。
  • 规则：始终核验你自己的模型。运行测试，从 devnet 开始，阅读官方文档，检查每个账户和金额，并在任何主网使用之前获得独立审计。未经核验的模型不是模型，而是猜测。
  • 未经审计，不构成建议。这些是教学示例，不构成金融、法律或税务建议，也不是持牌的支付或银行产品。在大多数国家，支付、稳定币和收单都是受监管的活动。
  • 安全。切勿把私钥粘贴到任何网站。不要安装 npm 包 @wen-community/wen-new-standard：npm 已因恶意将其移除。请从官方来源构建。

一个想法，公开核验

这不是日期时间线，而是方向的记录。每一层都把同一个问题回答得更完整一些：资产能否携带自己的规则，而不是依赖平台之间的信任？

起点

SPL Token

Solana 的通用代币标准：铸造、转账、销毁。一个简单的余额模型，没有内置行为。

解锁能力

Token-2022

代币内部的扩展：转账钩子、转账手续费、元数据、群组、必填备注、永久委托、保密转账。

形成标准

WNS

一种用于 NFT 的 Token-2022 配置：元数据、版税规则和群组都在单个铸币中。

付诸实践

WEN

weremeow 的一首诗用 WNS 铸造为 NFT，并在原始 SPL Token 程序上拆分为一万亿枚代币：这是该标准第一个大规模的故事。

平行路线

RWA 代币化

直接使用同一个 Token-2022 层（转账钩子、永久委托、默认冻结账户）来实现访问与合规规则，独立于 WNS 的 NFT 配置。

公开核验

Wen Open Lab

六个 Token-2022 模型、41 项测试、读者发现和七个安全检查点：代币内的规则，公开核验。

直接的技术延续 共同基础，独立路线

简短说明

WEN 不是 RWA。WEN 通过一个实际运行的资产展示协议能做什么：它是实践的证明，而不是合规级的金融工具。

WNS 是一种配置，不是平台。它是一组为 NFT 调校的 Token-2022 设置，不是独立的链或层。

改变的是可执行性。过去依赖市场善意的规则，现在可以存在于代币之中，任何人都能读取。

规则只证明它检查的东西，仅此而已。必填备注只证明备注存在；手续费必须符合程序的公式。公开测试让这些边界清晰可见。

同一条链条，在 Token-2022、WNS 与 Wen 页面中有讲解；转移代币前的七项检查见先证明，再信任。
