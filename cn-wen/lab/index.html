了解 Wen 是什么只是第一步，实验室是第二步：我们采用 Wen 背后的开放工具——WNS 代币布局、Solana Token-2022 和 Solana Pay——构建免费、可运行的模型，供开发者、商店、金融科技团队或银行学习、测试和复用。一切都是开放的，一步一步，公开进行。

为什么要做这件事

年鉴深入介绍了 Wen：那首诗、空投、WNS 标准，以及与 Jupiter 和 Solana 的联系。但仅有描述并不等于实用。当有人能拿起一个模型，运行它、检查它并在其上构建时，实用才真正开始。实验室正是这样做的，而且是公开地做，让 Wen 的技术遗产的价值被自由分享，而不是被锁起来。

构建过程中发现了两个真实的陷阱，这正是“核验你自己的模型”这条规则的由来：npm 包 @wen-community/wen-new-standard 因恶意已被移除；而 @solana/spl-memo 的新版本指向的备注程序，并不是 Token-2022 所检查的规范程序。代码中已处理这两点。

# get the files from lab/code/ (package.json, tsconfig.json, src/, test/)
npm install
npm run typecheck   # TypeScript, strict mode
npm test            # local Solana VM, no network, no real funds

Wen 在此模型中的位置

Wen 是这个实验室存在的原因。WEN 的故事让 WNS——这些模型背后的 Token-2022 标准——走向了大众（同质化代币 WEN 本身使用的是原始 SPL Token 程序）。下面每个模型都为 WEN 留出了一个可选、诚实的位置：作为支付或小费选项、忠诚度奖励，或仅仅作为社区对这项工作的签名。轨道本身是开放的，适用于任何代币。

Wen 的主线：一个合约，处处可见

实验室的每个模型都免费且开放，并带着同一个签名：$WEN 代币合约。复制它，在你自己的文档中重复它，使用前务必在浏览器上核验。

开放使用政策

  • 免费且开放。实验室的全部代码以 Apache License 2.0 发布，与 Wen Program Library 相同。无论是否商用，都可以使用、修改、发布；请保留许可声明。
  • 只用开放工具。基于公开且有文档的工具构建：Solana SPL Token-2022（Token Extensions）、Wen New Standard（WNS）的代币布局、Solana Pay，以及用于本地测试的 LiteSVM。
  • 规则：始终核验你自己的模型。运行测试，从 devnet 开始，阅读官方文档，检查每个账户和金额，并在任何主网使用之前获得独立审计。未经核验的模型不是模型，而是猜测。
  • 未经审计，不构成建议。这些是教学示例，不构成金融、法律或税务建议，也不是持牌的支付或银行产品。在大多数国家，支付、稳定币和收单都是受监管的活动。
  • 安全。切勿把私钥粘贴到任何网站。不要安装 npm 包 @wen-community/wen-new-standard：npm 已因恶意将其移除。请从官方来源构建。
