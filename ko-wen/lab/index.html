보기: 38초로 보는 랩

Wen이 기계처럼 영수증을 검증하고, 이어서 여섯 가지 모델과 그 뒤의 37개 검사를 보여 줍니다. 영상에 나오는 모든 것은 직접 실행할 수 있는 오픈 코드입니다.

Wen 영상 더 보기: 랩 영상 전체 · YouTube 채널 @wen-coin.

플레이어는 재생을 누른 뒤에만 YouTube에서 불러옵니다.

Wen이 무엇인지 아는 것이 첫걸음이었다면, 랩은 두 번째 걸음입니다. Wen 뒤에 있는 오픈 도구—WNS 토큰 구조, Solana Token-2022, Solana Pay—를 가져와 개발자, 상점, 핀테크 팀, 은행이 공부하고 테스트하고 재사용할 수 있는 무료로 작동하는 모델을 만듭니다. 모든 것이 공개되어 있으며, 한 단계씩, 공개적으로 진행됩니다.

왜 만들었나

이 연감은 Wen을 깊이 설명합니다. 시, 에어드롭, WNS 표준, Jupiter와 Solana와의 연결까지요. 하지만 설명만으로는 쓸모가 생기지 않습니다. 누군가 모델을 가져와 실행하고, 확인하고, 그 위에 무언가를 만들 수 있을 때 쓸모가 시작됩니다. 랩은 바로 그 일을 공개적으로 합니다. 그래서 Wen의 기술 유산이 지닌 가치가 잠겨 있지 않고 자유롭게 나뉩니다.

  1. 0 · 로드맵과 규칙. 이 페이지: 목적, 분야, 오픈 사용 정책, 검증 기록. 운영 중

  4. 3 · B2B 인보이스. 전송 수수료, 승인된 거래 상대, 필수 인보이스 메모. 9개 검사 통과
  5. 4 · 결제 브리지. Solana Pay 링크, 결제 감시, 검증, 상점으로 보내는 웹훅. 링크 검증됨
  6. 5 · 시뮬레이터. 내 숫자로 카드 결제 대행과 온체인 결제를 비교합니다. 대화형
  7. ★ · 이점과 활용. 누가 무엇을 얻는지, 어디에 맞고 어디에 맞지 않는지. 운영 중
  8. 6 · Devnet: 직접 재현. 공개된 스크립트가 공개 devnet에서 모델 1과 3을 실행하고 익스플로러 링크를 출력합니다. 누구나 새 빈 지갑으로 반복할 수 있습니다. 실행 준비 완료
  9. ✓ · 신뢰 사슬. 모든 핵심 주장에 상태와 출처를 표시합니다: 검증됨, 보도됨, 의견, 미검증, 상충. 운영 중
  10. ✎ · 열 가지 해설. 쉬운 말로 풀어 쓴 랩: 핵심 코드, 테스트, 한계를 담은 열 가지 "알고 계셨나요" 해설과 새 모델 5(영수증 검증기), 모델 6(토큰 검사기). 37개 검사 통과
  11. 7 · Wen Counter. 브라우저 속 무료 계산대: Solana Pay QR, 수신 전용, 지갑이 곧 신원, 절약 장부, 내려받는 키트. 57개 검사 통과
  12. 7.1 · 수신 전용 안전. 프로토콜, 법률 측면을 보여 주는 태양계 그림, 매일 정산하는 계산대 지갑, 그리고 모든 검사. 운영 중
  13. 6b · 공개 devnet 실행. 스크립트를 공개적으로 실행하고 devnet 페이지에 주소를 게시합니다. 다음
  14. 12 · WEN으로 결제하고 상점은 USDC로 받기. 구매자는 WEN으로 결제하고, 같은 트랜잭션 안의 Jupiter 스왑이 이를 바꿔 상점은 스테이블코인을 받습니다. 4단계와 7단계를 바탕으로 합니다. 다음 모델

  17. 10 · 위협 모델과 감사 체크리스트. 연산 한도, 계정 바꿔치기, 0원 전송, 키 관리. 계획됨
  18. 11 · 가맹점 플러그인 스케치. 온라인 상점이 웹훅으로 결제 브리지를 주문 시스템에 연결하는 방법. 계획됨

검증 기록

만드는 동안 실제 함정 두 가지가 드러났고, 그래서 규칙이 "내 모델은 직접 검증하라"입니다. npm 패키지 @wen-community/wen-new-standard는 악성으로 판명되어 삭제되었고, @solana/spl-memo의 최신 버전은 Token-2022가 확인하는 정식 메모 프로그램과 다른 프로그램을 가리킵니다. 두 가지 모두 코드에서 처리했습니다.

직접 실행하기

# get the files from lab/code/ (package.json, tsconfig.json, src/, test/)
npm install
npm run typecheck   # TypeScript, strict mode
npm test            # local Solana VM, no network, no real funds

devnet에서는: Solana CLI로 지갑을 만들고 devnet SOL을 요청한 다음, 각 파일의 전송 함수를 호출하기 전에 KEYPAIR와 선택적으로 RPC_URL을 설정하세요. 새 빈 지갑으로 시작하세요.

그림으로 보는 Wen

이 모델에서 Wen의 자리

Wen은 이 랩이 존재하는 이유입니다. WEN의 이야기가 이 모델들 뒤의 Token-2022 표준인 WNS를 대중에게 알렸습니다(대체 가능한 WEN 토큰 자체는 원래의 SPL Token 프로그램을 씁니다). 아래 각 모델은 WEN을 위한 선택적이고 정직한 자리를 보여 줍니다. 결제나 팁 옵션, 충성도 보상, 혹은 작업에 남기는 커뮤니티의 서명으로요. 레일 자체는 공개되어 있어 어떤 토큰과도 작동합니다.

Wen의 실: 하나의 컨트랙트, 어디에나

랩의 모든 모델은 무료이고 공개되어 있으며, 모두 같은 서명을 지닙니다. 바로 $WEN 토큰 컨트랙트입니다. 복사해 내 문서에도 적어 두고, 쓰기 전에는 반드시 익스플로러에서 확인하세요.

오픈 사용 정책

  • 무료이고 공개. 랩의 모든 코드는 Wen Program Library와 같은 Apache License 2.0으로 공개됩니다. 상업적이든 아니든 쓰고, 고치고, 배포하세요. 라이선스 고지만 유지하면 됩니다.
  • 오픈 도구만. 공개되어 있고 문서화된 도구로 만듭니다: Solana SPL Token-2022(Token Extensions), Wen New Standard(WNS) 토큰 구조, Solana Pay, 로컬 테스트용 LiteSVM.
  • 규칙: 내 모델은 언제나 직접 검증하라. 테스트를 돌리고, devnet에서 시작하고, 공식 문서를 읽고, 모든 계정과 금액을 검토하고, 메인넷에 쓰기 전에 독립 감사를 받으세요. 검증하지 않은 모델은 모델이 아니라 추측입니다.
  • 감사받지 않았고, 조언이 아닙니다. 교육용 예제입니다. 금융·법률·세무 조언이 아니며, 인가받은 결제나 은행 상품도 아닙니다. 대부분의 나라에서 결제, 스테이블코인, 결제 대행은 규제 대상 활동입니다.
  • 보안. 개인 키를 웹사이트에 절대 붙여 넣지 마세요. npm 패키지 @wen-community/wen-new-standard는 설치하지 마세요. npm이 악성으로 삭제했습니다. 공식 소스로 빌드하세요.
